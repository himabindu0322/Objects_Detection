# Objects_Detection
A complete Full Stack AI-powered Object Detection System built using YOLOv8, FastAPI, OpenCV, HTML, CSS, and JavaScript.  This project can detect objects from:  Images Videos Live Webcam Feed  The system performs real-time object detection with bounding boxes and labels using the powerful YOLOv8 model.

# ✨ Features
✅ Image Object Detection

✅ Video Object Detection

✅ Live Camera Detection

✅ Real-Time Bounding Boxes

✅ YOLOv8 AI Model Integration

✅ FastAPI Backend

✅ Interactive Frontend UI

✅ Real-Time Frame Processing

✅ Browser Webcam Support

✅ Full Stack AI Application
